You are helping build Reno in the existing GitHub repo:

https://github.com/nsirivolu27/RENO

Reno is an MIT open-source AI renovation app for homeowners and renovation professionals. The product should let someone upload or take a photo of a residential or corporate space, describe the interior design changes they want, generate a realistic before/after renovation concept, save concepts into client projects, and present those concepts professionally.

IMPORTANT
Work in the existing repo only. Do not create a new app from scratch unless the repo is empty. Preserve existing behavior. Make small, reviewable commits. Do not overwrite unrelated work from Codex or Claude.

CURRENT PRODUCT DIRECTION
Reno should feel less like a generic AI dashboard and more like a polished interior design / renovation studio tool.

Target users:
1. Homeowners:
   - Upload a room photo.
   - Pick room type, style, restyle/renovate mode.
   - Describe furniture, lighting, paint/walls, flooring, fixtures, and what must stay.
   - Generate before/after concepts.
   - Download or save results.

2. Renovators / designers:
   - Create client demo projects.
   - Generate multiple concepts for the same space.
   - Save, favorite, compare, export, and present before/after proposals.
   - Use Reno during a client meeting, including on mobile.

TECH CONSTRAINTS
- Monorepo with npm workspaces.
- Next.js 15 App Router web app in `apps/web`.
- Expo mobile app in `apps/mobile`.
- Shared TypeScript package in `packages/core`.

- Plain CSS only in `apps/web/app/globals.css`.
- No Tailwind.

- No new dependencies unless absolutely necessary and explained.
- Keep dark theme, but make it warmer and more premium.
- Keep existing API routes and provider architecture.
