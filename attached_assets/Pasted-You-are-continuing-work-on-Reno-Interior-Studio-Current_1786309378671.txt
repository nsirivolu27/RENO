GOAL
Continue building Reno from the current Replit design into a real demo-ready AI renovation product. Keep the warm, premium, mobile-first interior studio look, but make the product more functional and closer to the existing Reno monorepo vision.

Reno should let a homeowner or renovator:
- upload/take a photo of a room
- define the room type
- choose restyle vs full renovation
- pick a visual style
- describe furniture, lighting, paint/walls, flooring, fixtures, and must-keep constraints
- generate a before/after concept
- save multiple concepts
- present the result clearly to a client

DESIGN DIRECTION
Keep the current Replit UI direction:
- warm dark brown/black interior-studio feel
- large image-first cards
- mobile-first layout
- elegant serif headings
- simple professional controls
- not a generic AI dashboard
- not overly “AI-looking”
- suitable for showing to an actual client

Use these as visual inspiration, not exact copies:
https://dribbble.com/search/interior-app
https://dribbble.com/shots/27004179-Ai-Home-Interior-App-design-Design

IMPORTANT PRODUCT STANDARD
This needs to feel like a design/renovation professional could open it during a home walkthrough and say:
“Here’s the original room, here’s the proposed concept, here are the design choices, and here’s what we would change.”

2. Demo Generation Mode
Until the real API provider is connected, create a polished demo generation mode:
- It should not look broken or fake.
- It should use the uploaded image as the “before”.
- The “after” can be a generated demo concept card or stylized local preview, but it must feel like a credible placeholder.
- Clearly label it as Demo Mode only when needed.
- The user should be able to walk through the full UX without an API key.

3. Before / After Experience
Make this the most important product surface:
- Large before/after comparison
- Compare slider or toggle
- Before only / after only tabs
- Design summary beside or below it
- Download result button
- Regenerate button
- Save concept button

The before/after should be mobile-friendly and client-presentable.

4. Saved Concepts / Project Demo
Add a lightweight local project system using browser localStorage:
- Save generated concepts
- Show saved concepts in a “Project” or “Concepts” page/section
- Each concept should include:

  - after/demo image
  - room
  - style
  - scope
  - design brief summary
  - created date
- Allow favoriting one or more concepts
- Allow deleting a concept
- Add a simple “Presentation View” that hides controls and shows a clean before/after proposal.
